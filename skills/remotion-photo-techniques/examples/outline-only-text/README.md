# TEXT_OUTLINE — прозрачный текст с обводкой

Самостоятельный пример Remotion: контур слова раскрывается слева направо, а движущийся фон остаётся видимым внутри букв. В примере используется исходная процедурная сцена; исходное видео не требуется.

```bash
npm ci
npm run lint
npm run render
```

Композиция `OutlineOnlyTextDemo`: 1280 × 720, 60 fps, 120 кадров. Для своей сцены помести [`OutlineOnlyText`](../../assets/techniques/outline-only-text.tsx) поверх изображения или видео и задай текст, цвет и толщину контура, шрифт и кадры раскрытия.
