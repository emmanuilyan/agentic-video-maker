# TEXT_OUTLINE — контурные буквы с прозрачной серединой

## Результат

Белый контур крупного слова постепенно открывается слева направо. Заполнение букв полностью прозрачное: картинка под титром видна без цветной подложки. После раскрытия контур удерживается, пока фон продолжает двигаться. [Превью](../../assets/previews/TEXT_OUTLINE-reference.mp4) — пользовательский утверждённый рендер, 1280 × 720, 60 fps, 120 кадров. Приём создан по запросу пользователя; внешнего видеореференса у него нет.

## Слои и таймлайн

| Слой | Реализация |
| --- | --- |
| Фон | Любое фото, видео или композиция на всю площадь кадра. В примере цветные градиенты и световые пятна перемещаются каждый кадр. |
| Надпись | SVG `<text fill="none" stroke="...">`, центр по X, базовая линия `0.57 × высота`; контур в примере 5 px при размере шрифта 220 px. |
| Раскрытие | SVG `clipPath` с прямоугольником шириной `ширина кадра × progress`; `progress` растёт от 0 до 1 на кадрах 6–34. |
| Лёгкий вход | Масштаб слова одновременно растёт от 0.96 до 1 вокруг центра слова. Кадры 34–119 удерживают финальное состояние. |

Компонент [`OutlineOnlyText`](../../assets/techniques/outline-only-text.tsx) возвращает только прозрачный SVG-оверлей. Передавай его поверх любого фона. `text`, `strokeColor`, `strokeWidth`, `fontFamily`, `fontSize`, `fontWeight`, `revealStartFrame`, `revealEndFrame`, `baselineY` позволяют менять вид без правки компонента. Значения кадров относятся к локальному времени композиции или `Sequence`, в которую помещён компонент.

```tsx
<AbsoluteFill>
  <OffthreadVideo src={footage} muted />
  <OutlineOnlyText
    text="КОНТУР"
    strokeColor="#fff5df"
    strokeWidth={5}
    fontSize={220}
    revealStartFrame={6}
    revealEndFrame={34}
  />
</AbsoluteFill>
```

Импортируй `OutlineOnlyText` из `assets/techniques/outline-only-text.tsx`. Для другого формата кадра скорректируй `fontSize` и при необходимости `baselineY`. Системный `Arial Black` может отличаться на другой машине; для одинаковых очертаний подключай файл шрифта в проекте.
