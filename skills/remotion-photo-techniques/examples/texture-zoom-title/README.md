# TEXTURE_ZOOM_TITLE

Standalone Remotion example for a phrase whose glyphs carry a moving color texture, followed by a zoom crossfade to the next shot.

```bash
npm ci
npm run dev
npm run render
```

The reusable component is [`TextureZoomTitle`](../../assets/techniques/texture-zoom-title.tsx), the measured recipe is in [effect.md](effect.md), and the preview is [`TEXTURE_ZOOM_TITLE-reference.mp4`](../../assets/previews/TEXTURE_ZOOM_TITLE-reference.mp4). The example uses original synthetic scenes and texture; replace its `outgoing` and `incoming` nodes with your own footage.
