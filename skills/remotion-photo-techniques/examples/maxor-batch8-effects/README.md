# Шесть утверждённых приёмов Maxor: 0:59.65–1:18.35

Запускаемый Remotion-пример для шести коротких эпизодов из [видео Maxor](https://www.youtube.com/watch?v=kO9HmhwGzXs). Код композиций — [src/Effects.tsx](src/Effects.tsx), покадровые рецепты и ограничения — [effect.md](effect.md). Формат каждой композиции: 1280 × 720, 60 fps, длительность от 0.85 до 3.3 с.

```sh
npm install
npx remotion render src/index.tsx 03-part-one-title-card out/part-one.mp4
```

Другие ID: `01-dog-doing-caption`, `02-god-freed-frame`, `04-made-by-maxor-logo`, `05-keyboard-collage-caption`, `06-character-smear-title`. Исходное видео `public/source-59-90.mp4` нужно только для демонстрации на прежнем материале. При переносе приёма заменяйте его и исходные изображения своими медиа; текстовые параметры указаны в [рецепте](effect.md).

Превью в галерее — точные самостоятельные Remotion-рендеры из последних утверждённых сравнений. Они сохранены без повторного кодирования; постеры получены из этих же MP4.
