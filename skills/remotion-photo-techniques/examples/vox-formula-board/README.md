# VOX_FORMULA_BOARD

Approved 540x960 Remotion scene: a worn black board, VOX FORMULA heading, three question-mark boxes and three animated connector lines.

Run `npm install` and `npm run render`. Composition: `VoxFormulaBoard`, 24 fps, 44 frames. Implementation: [component](../../assets/techniques/vox-formula-board.tsx). Copy all four files in `public/` into the destination Remotion project's `public/` directory. See [recipe](effect.md) and [approved preview](../../assets/previews/VOX_FORMULA_BOARD-reference.mp4).
