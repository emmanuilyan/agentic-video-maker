# Six approved Maxor effects

These six standalone Remotion compositions recreate short passages from [Maxor's video](https://www.youtube.com/watch?v=kO9HmhwGzXs). The components, timing, layer order, and reuse notes are in [effect.md](effect.md). All demos are 1280 × 720 at 60 fps and run for at most 2.5 seconds.

Install dependencies with `npm install`, then render a composition, for example:

```sh
npx remotion render src/index.tsx 03-japan-map-callout out/japan.mp4
```

The `public/` images are source-specific still plates and cutouts. Replace these with your own footage or images when reusing a motion recipe. The gallery previews are the exact standalone renders from the final user-approved comparisons; the original clips and two-panel comparisons are not included in the gallery.
