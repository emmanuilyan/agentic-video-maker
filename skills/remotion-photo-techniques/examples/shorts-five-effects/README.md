# Five approved Shorts effects

Echo, Glow, CC Lens, CC Pixel Polly, and Motion Tile from the SonduckFilm reference. [Parameters, source intervals, and implementation recipe](effect.md).

```sh
npm install
npm run studio
npm run typecheck
npm run render
```

Individual composition IDs: `Echo`, `Glow`, `Lens`, `PixelPolly`, `MotionTile`. Each gallery preview is the exact standalone render reviewed by the user.
