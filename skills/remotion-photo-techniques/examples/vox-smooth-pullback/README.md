# VOX_SMOOTH_PULLBACK

Approved 360×640 Remotion example at 24 fps for 72 frames. The photo makes one continuous smooth pullback; the title and arrow appear after the move.

Run `npm install`, then `npm run typecheck` and `npm run render`. Copy `public/full.png` and use the reusable [VoxSmoothPullback](../../assets/techniques/vox-smooth-pullback.tsx) component with your own `imageSrc`. The [recipe](effect.md) records the frame timing. The [approved preview](../../assets/previews/VOX_SMOOTH_PULLBACK-reference.mp4) is the exact right-hand Remotion render from the user's latest review comparison.
