# Shortform transitions

Six standalone 9:16 Remotion compositions. Each transition joins two React scenes over 18 frames at 30 fps.

```sh
npm install
npm run typecheck
npm run studio
npm run render -- SWIPE-PUSH out/SWIPE_PUSH.mp4
```

Composition IDs are `SWIPE-PUSH`, `SPIN-BLUR`, `ZOOM-PUNCH`, `FLASH-BEAT`, `GLITCH-SLICE`, and `COVER-SWIPE`. The reusable component is in `../../assets/techniques/shortform-transitions.tsx`; the plates here only make the motion easy to inspect.
