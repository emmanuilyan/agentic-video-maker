# CAMERA_PHOTO_PAN — боковой пролёт по фотографиям

Запускаемый пример горизонтального пролёта камеры по соседним фотографиям. Основан на участке [A$AP Rocky — Kids Turned Out Fine](https://www.youtube.com/watch?v=FUQI-o02JYU), 42.8–45.8 с. Версия v3 одобрена пользователем.

```bash
npm install
npm run typecheck
npm run render
```

- [Библиотечный компонент](../../assets/techniques/lateral-photo-pan.tsx) принимает две или больше фотографий и ключевые позиции виртуальной камеры; `src/LateralPhotoPan.tsx` содержит ту же реализацию внутри самостоятельного демо.
- `src/Demo.tsx` — настройка под пример.
- [Одобренное превью](../../assets/previews/CAMERA_PHOTO_PAN-reference.mp4) — точный Remotion-рендер, показанный пользователю; `out/camera-photo-pan.mp4` создаётся командой `npm run render`.
- Папка `out/` локальная и игнорируется Git. Исходное двухпанельное сравнение использовалось для ревью; переносимое превью содержит только Remotion-панель.
- `effect.md` — рецепт по проверенной версии.

Три JPEG в `public/` извлечены как стоп-кадры из указанного клипа для демонстрации механики. Исходное видео не воспроизводится внутри Remotion-композиции. Для собственного проекта замените `src` фотографий в `src/Demo.tsx`.
