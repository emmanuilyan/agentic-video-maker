# CC_LENS — сферическое раскрытие

## Источник и результат

Источник: [YouTube Shorts, SonduckFilm](https://www.youtube.com/shorts/8pl2qxO3Uoc), фрагмент 00:20.00–00:23.00. В ролике показано пять эффектов; этот кандидат выбран по контексту задачи о переходах.

Результат: `CCLens`, 506 × 700, 30 FPS, 90 кадров / 3 секунды. [Одобренное превью](../../assets/previews/CC_LENS-reference.mp4).

Реализация: [LensWarp.tsx](../../assets/techniques/lens-warp.tsx), демонстрация: [LensDraft.tsx](src/LensDraft.tsx).

Это стилизованная адаптация, не точная копия CC Lens из After Effects. Сохраняет круг на чёрном фоне, сферическую деформацию, раскрытие и возврат к плоскому изображению. Исходная типографика заменена SVG. В оригинале сильнее изгибаются и повторяются белые и зелёные фрагменты; черновик показывает более мягкую радиальную проекцию. Показанная адаптация одобрена пользователем 30 сентября 2026 года сообщением «продолжай» после просмотра сравнения.

## Визуальное устройство

Картинка проходит через полноэкранный GLSL шейдер. Расстояние до центра измеряется с поправкой на пропорции кадра: `metric = (delta.x * width/height, delta.y)`. За радиусом линзы выводится чёрный цвет. Внутри UV преобразуются через сферическую функцию `asin(q)/(q*pi/2)`, где `q = distance/radius`. При малом радиусе вся прямоугольная SVG карта проецируется в круг. При большом радиусе используется UV исходного прямоугольника с радиальной деформацией.

| Слой | Геометрия | Оформление |
| --- | --- | --- |
| Чёрная подложка | Весь кадр | RGB 0,0,0 |
| SVG фон | Центр 0.5W, 0.5H; полный кадр | Тёмный фон, белые дуги, диагональная зелёная типографика |
| Сферическая проекция | Центр 0.5W, 0.5H; радиус в долях H | GLSL маска круга, затемнение края, тонкий ободок |
| Заголовок в полной фазе | Центр; строки TOP 5 / EFFECTS | Arial Black/Arial, weight 900; 69/65 px на ширине 506; белый |

В малой сфере заголовок находится внутри текстуры и деформируется вместе с ней. В полной фазе это отдельный прозрачный SVG над фоном. Такое разделение — выбранная адаптация, а не подтверждённая структура исходного проекта AE.

## Временная схема

Кадры относительно начала эффекта. При иной длительности `lensState` нормализует их к шкале 0–89.

| Кадры | Действие | Радиус / сила |
| --- | --- | --- |
| 0–30 | Удержание сферы | 0.34H / 0.92 |
| 31–38 | Быстрое раскрытие | 0.34 → 0.64H / 0.92 → 0.95, smoothstep |
| 35 | Замена общей текстуры на фон без заголовка | Появляется отдельный белый заголовок |
| 39–64 | Удержание полной линзы | 0.64H / 0.95 |
| 65–89 | Ослабление деформации | 0.64 → 1.15H / 0.95 → 0, smoothstep |

Звук не воспроизводится. В исходнике между демонстрационными состояниями есть монтажные изменения; в черновике между ними построено короткое раскрытие.

## Параметры

`LensWarp` принимает `src` (путь к изображению), `durationInFrames` (целое >= 2), `frame` (необязательный локальный кадр), `intensity` (по умолчанию 1; рабочий диапазон 0–1), `center` (UV пара, по умолчанию [0.5, 0.5]). Длительность масштабирует всю временную схему. Для другого изображения замените SVG путь; функция не содержит встроенного видеоклипа из оригинала.

## Повторение

1. Создать изображение нужного кадра или слоя, сохранив пропорции композиции.
2. Передать его в `LensWarp` и использовать `ThreeCanvas` с `dpr=1`.
3. Строить состояние исключительно из номера кадра; анимация не зависит от времени браузера.
4. Если нужен читаемый заголовок после раскрытия, использовать слой `Img` из демонстрации и круглую CSS маску с радиусом `state.radius * height`.
5. Рендерить с `--gl=angle`. Зависимости перечислены в package.json; перед запуском выполните npm install.

Команды: `npm run typecheck`, `npm run render`.

## Проверка и неопределённость

`tsc --noEmit` прошёл. Remotion успешно отрендерил все 90 кадров в H.264. Сравнение использует оригинал, обрезанный до области предпросмотра AE (x=40,y=0,w=253,h=350 в исходнике 360×640), затем увеличенный до 506×700. Контрольные кадры: начало, 1.5 и 2.5 секунды.

Радиус, сроки раскрытия и сила деформации — оценки по видимым кадрам. В исходнике размер окна AE меняется, поэтому эта обрезка не даёт строгого сравнения относительного масштаба всех элементов. Белые фрагменты вокруг сферы, набор фоновых слов, шрифт и чистая тёмная текстура заменены собственной графикой. Точное внутреннее преобразование CC Lens не подтверждено; здесь реализован самостоятельный сферический шейдер.
