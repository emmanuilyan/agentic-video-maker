# RAPID_PHOTO_FLIPBOOK — быстрое перелистывание фотографий

В исходнике [A$AP Rocky — Sundress](https://www.youtube.com/watch?v=Ec3LoKpGJxY) на **1:57–1:59** фотографические планы быстро сменяют друг друга без видимого поворота страницы. Отдельный компонент `PhotoFlipbook` делает жёсткую смену изображений на заданных кадрах. Демо включает четыре кадра входа из предыдущего монтажа, затем 22 плана по два кадра. Внутри некоторых пар есть небольшое движение, поэтому компонент поддерживает необязательные `frameSources`.

## Запуск

```bash
npm install
npm run typecheck
npm run render
```

Composition `PhotoFlipbookReview`: 1280×720, 24 fps, 48 кадров. Для рендера можно указать существующий Chrome через `--browser-executable`.

Кадры исходника в `public/photos` используются для воспроизведения измеренного примера; они не нужны самому компоненту. В альбомный кадр каждый план заполняет весь экран через `object-fit: cover`. Звук не включён.
