# 3D — CAROUSEL_ORBIT

Одна непрерывная круговая сцена: фотографии проходят перед камерой, вырезанные объекты повторяются на двух кольцах, камера сильно приближается к выбранной карточке и плавно отъезжает к следующей. Пространство сохраняется при смене смыслового акцента. Это проекция плоских карточек в 3D; глубина внутри самой фотографии не создаётся.

[Реализация](../assets/techniques/carousel.tsx) выделена из проверенного монтажа «Дойти до ручки». [Видео-пример](../assets/previews/CAROUSEL_ORBIT-reference.mp4) — участок 17,067–25,000 секунды готового ролика: 238 кадров, 30fps, уменьшенный до540×960, без звука. Видимая надпись принадлежит ролику, компонент её не добавляет. Фотографии из примера не входят в API и не нужны для нового монтажа.

## Подключение

Скопируй всю `assets/techniques` в проект по [интеграции](integration.md). Для пяти фото и вырезанного объекта импортируй `CarouselOrbit` напрямую; `PhotoTechnique technique="CAROUSEL_ORBIT"` — только четырёхкарточное демо без вырезанных объектов.

```tsx
import {Img, Sequence, staticFile} from 'remotion';
import {CarouselOrbit, CarouselPhoto} from './photo-techniques';

// src и размеры замени на реальные исходники. Углы заданы в радианах.
const photos: CarouselPhoto[] = [
  {src: staticFile('photos/a.jpg'), width: 1200, height: 1600, angle: 0},
  {src: staticFile('photos/b.jpg'), width: 1200, height: 800, angle: 1},
  {src: staticFile('photos/c.jpg'), width: 1200, height: 1600, angle: 2,
   objectPosition: '76% 50%'},
  {src: staticFile('photos/d.jpg'), width: 1200, height: 1600, angle: 3.25},
  {src: staticFile('photos/e.jpg'), width: 1200, height: 800, angle: 4.4},
];

export const ClosingScene = () => (
  <Sequence from={512} durationInFrames={238}>
    <CarouselOrbit photos={photos} durationInFrames={238}
      decorationCount={40}
      decoration={<Img src={staticFile('photos/cutout.png')}
        style={{width: '100%', height: '100%', objectFit: 'contain'}}/>}/>
  </Sequence>
);
```

`cutout.png` — подготовленный прозрачный вырезанный объект, не прямоугольная фотография. Можно передать собственный JSX с CSS/SVG-маской. При повторении SVG определяй общую маску один раз с уникальным ID снаружи карусели; не размножай одинаковые `id` внутри каждой копии. В оригинале хлебная ручка вырезана маской из интернет-фотографии, без генерации.

`Sequence` уже делает время локальным: на первом кадре карусели `useCurrentFrame()` равен0. Передавай длину именно сцены. Не создавай новую Sequence при переходе от третьей фотографии к четвёртой. Длина238 кадров здесь — пример из ролика, не универсальная длительность.

## Камера и геометрия

Время нормализуется в0…237 через `localFrame / (durationInFrames-1) * 237`. Встроенная траектория рассчитана на углы фото из примера; для другого расположения передай свой `camera` или адаптируй `carouselCamera`.

| Фаза | Нормализованные кадры | Параметры |
|---|---|---|
| Вращение | 0…69 | Угол камеры −0.9→2, easing bezier(.38,.1,.62,.9). |
| Экстра-зум к третьей карточке | 60…84 | zoom1→3.4; focusX0→28, focusY0→−180; easing bezier(.22,.8,.22,1). |
| Удержание крупного плана | 84…102 | Та же камера, крупный план остаётся читаемым. |
| Отъезд к четвёртой карточке | 102…130 | Угол2→3.25, zoom3.4→1.42; focusX/Y возвращаются к0. |
| Финальное удержание | 130…237 | Камера сохраняет конечное состояние. |

Для объекта с относительным углом `a = objectAngle - camera.angle`: `depth = 1300 + radius*(1-cos(a))`, `scale = 1100/depth`, `x = sin(a)*radius*scale`, `y = objectY*scale`. Радиус карточек1420; кольца декора1130 и1660. Сортируй весь общий список от дальних объектов к ближним и назначай последовательный `zIndex`. Стабильные `key` сохраняют идентичность карточек.

Внутри каждой карточки локальный `perspective(1000px) rotateY(-sin(a)*29deg)` задаёт наклон. Общего `preserve-3d` и прозрачных направляющих нет: пересекающиеся CSS-плоскости могут внезапно обрезать или перекрыть изображения. Движение камеры — один `scale(zoom) translate(-focusX,-focusY)`; перестановка transform меняет точку зума.

## Что настраивать

| Параметр | Назначение |
|---|---|
| `photos` | Один или больше `CarouselPhoto`: обычные src/width/height плюс обязательный angle, optional objectPosition и fit. Пять — только пример. |
| `durationInFrames`, `frame?` | Длина сцены и необязательный управляемый локальный кадр. Обычно frame не нужен. |
| `camera?` | `{angle, zoom, focusX, focusY}` в координатах эталонной сцены; полностью заменяет встроенную траекторию. |
| `decoration`, `decorationCount` | Повторяемый прозрачный JSX; по умолчанию40 копий. Без decoration слой отсутствует. Размер контейнера660×495, положение и радиусы меняются в коде при адаптации другого силуэта. |
| `width`, `height` | По умолчанию размеры composition. Эталонная вертикальная сцена1080×1920 пропорционально вписывается; широкий формат требует художественной перераскладки. |
| `borderColor`, `background` | Рамка и фон сцены. |
| `topShade` | По умолчанию true: к финалу затемняет верх для отдельного акцентного титра. Для чистой фотосцены можно отключить. |

При смене крупного плана настрой `objectPosition` по реальному исходнику и `focusX/Y` по детали. Значение76% в примере было выбрано для конкретного портрета, не для любой фотографии. Количество копий, цветовая палитра и сила зума также относятся к этому рецепту и могут меняться по брифу.

## Проверка

Проверь начало, движение, пик зума, соседние кадры смены фокуса и конец. Для длины238 это кадры0,28,29,57,58,69,84,102,129,130,237. Для другой длины пересчитай границы через `(duration-1)/237`.

- Объекты переходят перед/за карточками согласно глубине; нет произвольного исчезновения, скачка масштаба или сброса угла на монтажной границе.
- На пике зума нужная деталь узнаваема и не вышла из кадра. Финальная карточка читается после отъезда.
- Повторный рендер одного кадра совпадает; вся анимация зависит от кадра, без CSS animation и Math.random.
- Контактный лист делай с зазорами: соседние кадры вплотную могут выглядеть как ошибочное наложение фотографий. Подозрительное перекрытие проверяй в отдельном кадре.

Экспортируй отдельную composition с ID `CAROUSEL-ORBIT`, затем проверь MP4 через ffprobe и полное декодирование FFmpeg. Превью исходного ролика сохраняет внешний вид рецепта; новый набор фото оценивай заново.

Сохранённый компонент проверен на Remotion4.0.522 / React19.2.3: TypeScript, рендер прямого API с пятью фото и40 вырезками внутри Sequence со смещением, сравнение шести контрольных кадров с исходной реализацией и рендер четырёхкарточного адаптера. Видео-пример содержит238 кадров и декодируется без ошибок.
