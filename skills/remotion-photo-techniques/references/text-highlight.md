# TEXT_HIGHLIGHT: жёлтая плашка за текстом

[Референс](https://www.youtube.com/watch?v=n3IYmdy6d4Y), 14,14–15,33 с. В кадре две жёлтые прямоугольные полосы раскрываются слева направо **позади уже видимого чёрного текста**. Нижняя полоса отстаёт на 6 исходных кадров (`24000/1001` fps, ≈0,25 с). Движение быстро разгоняется, затем плавно затухает. Цвет полностью открытой области близок к RGB `(232,217,67)`; после H.264 кодирования выбранный в компоненте `#E9D642` дал близкий видимый результат.

## Отдельный компонент

Скопируй `assets/techniques/text-highlight.tsx` в проект и используй `YellowTextHighlight`. Ему нужны только React и Remotion. Он не требует фотографий и подходит для наложения поверх видео, рисунка или однотонного фона.

```tsx
import {YellowTextHighlight} from './text-highlight';

<YellowTextHighlight
  lines={['"synovial" partially derives', 'from ovum, Latin for egg']}
  width={306}
  lineHeight={27}
  fontSize={25}
  startFrame={15}
  staggerFrames={6}
  revealFrames={19}
  style={{position: 'absolute', left: 134, top: 286}}
/>
```

Этот пример рассчитан на композицию 1280×720, 24 fps, где кадр 0 совпадает с 13,5 с референса. `startFrame=15` даёт первый видимый жёлтый пиксель около 14,14 с. Полосы имеют общий bounding box `x≈134…440`, `y≈286…340`: `x/W≈0,105`, `y/H≈0,397`, `width/W≈0,239`. Высота каждой строки 27 px. При другом разрешении масштабируй геометрию и шрифт; при другом FPS масштабируй интервалы в кадрах.

| Prop | Роль |
| --- | --- |
| `lines` | Строки с отдельной плашкой под каждой. |
| `width`, `lineHeight`, `fontSize` | Размер блока, высота строки и размер букв в пикселях. |
| `highlightColor` | Цвет заливки, по умолчанию `#E9D642`. |
| `textColor`, `textStyle`, `style` | Текст и положение всего блока. |
| `startFrame` | Начало верхней строки. |
| `staggerFrames` | Задержка каждой следующей строки; 6 при 24 fps. |
| `revealFrames` | Длина раскрытия; 19 при 24 fps. |
| `frame` | Необязательный локальный кадр для обёрток; при обычном использовании берётся из `useCurrentFrame`. |

Ход правой кромки хранится в компоненте как измеренные доли ширины по кадрам 0–19. Текст остаётся неподвижным и видимым до начала анимации. Заливка сохраняется после раскрытия.

## ID для фото-демо

`<PhotoTechnique technique="TEXT_HIGHLIGHT" photos={photos} text={'ПЕРВАЯ СТРОКА\nВТОРАЯ СТРОКА'} durationInFrames={180} />` показывает приём поверх каждого из четырёх фото. В демо кадр разбит на четыре участка по 45 нормализованных кадров; на каждом выделение запускается заново. У ID жёлтый цвет по умолчанию. Для наложения на уже собранную сцену используй отдельный компонент выше: он сохраняет точные 24 fps параметры и не требует массива фото.

## Проверка

Сравни начало около 14,14 с, положение кромок около 14,39 и 14,64 с и полное раскрытие после 15,33 с. Исходный фон, шрифт и небольшое движение камеры в референсе не являются частью этого компонента. [Запускаемый пример](../examples/yellow-highlight/README.md) и [готовый рендер](../assets/previews/TEXT_HIGHLIGHT-reference.mp4) входят в скилл.
