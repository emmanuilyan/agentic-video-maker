# Пять нетекстовых эффектов 164.80–216.80

Статус: утверждены пользователем 2026-10-08. Сохранены точные версии из последнего сравнения.

60 fps, 1280×720. Сравнения: оригинал слева, Remotion справа.

- SelectiveColor: grayscale-подложка + красный hue mask через SVG, анимируемая сила, камера, смена плана на кадре 62.
- UiCollage: отдельные UI-панели, портрет и цветной tooltip сверху; выход на кадре 80.
- DarkFocus: sharp center/blur background с радиальной маской, vignette, color blend, мягкий push-in.
- MemeInUi: camera scale 1→1.5 на кадрах 9–14; clipped video reveal на кадрах 12–24.
- ReactionGlitch: focus closeup; cut кадр 36; RGB shift 20→0 на кадрах 36–52, blur/rotation и purple blend.

## Ограничения
Это реализации монтажных механизмов. Движение игровых персонажей в основных сценах заменено стоп-кадрами. Сопутствующие титры не воссоздавались как отдельные текстовые эффекты. Панели UI и tooltip взяты отдельными растровыми вырезками. Для focus фон под надписью приблизительно восстановлен текстурой крыши. В combat фон под исходной вставкой восстановлен inpaint; часть зоны перекрыта реакцией. Мемная декоративная рамка частично присутствует в вырезке; компонент добавляет border/mask. Защитный шар и игровой интерфейс — исходные игровые материалы, не новые Remotion VFX.

Нельзя утверждать покадровое совпадение. Проверены выбранные ключевые кадры, typecheck и количество кадров всех пяти экспортов. Внешнее ревью ChatGPT не состоялось: в существующем чате отображается исчерпанный лимит.
