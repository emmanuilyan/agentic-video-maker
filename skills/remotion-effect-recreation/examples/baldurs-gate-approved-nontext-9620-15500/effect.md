# Нетекстовые приёмы Maxor: рецепты

## Исходник и результат

[BG3 Review](https://www.youtube.com/watch?v=I6qlhmjkQ44). Точные диапазоны, композиции и длительности — в [README](README.md). [Реализация](src/effects.tsx);1280×720,60fps. Все координаты ниже заданы для этого холста; нормализуй x,w делением на1280 и y,h на720, затем умножай на размеры нового холста.

## Механика и таймлайн

### MAXOR_CUTOUT_CARD_SWAP

Слои: движущийся фон → прозрачный мем → заменяющая карточка. f24–33: вырезанная крыса растёт из(160,282,250,148) в(116,264,329,194). f39–46: рамка заменяет вырезку и растёт из(164,228,230,275) в(142,210,258,305). f54: мгновенная замена на лицо с прямоугольником(136,188,271,338). Рамка и надпись — растровые материалы, не отдельная типографическая анимация.

### MAXOR_PAIRED_IMAGE_GROWTH

Фон → левая карточка → правая карточка. f7–16: левая из(126,199,264,282) в(38,105,440,470). f27–35: правая из(921,192,258,287) в(840,102,420,468), левая удерживается. f55: выход в следующую сцену. Рост линейный; промежуточный easing приблизительный.

### MAXOR_HAND_COLLAGE_RGB

Весь коллаж входит с f9. q=clamp(1−(f−9)/10). RGB-сдвиг13q px; blur5q px; горизонтальный сдвиг−240q+13q·sin(2.3f), вертикальный5q·cos(f); scale1+0.4q; rotate−8q градусов; origin90%50%. Под движущейся сценой её статичная копия заполняет открывающиеся края. Затем карточки растут и сохраняют прежние: f9–19,(918,273,175,222)→(824,166,318,403); f31–37,(780,410,168,218)→(714,291,305,397); f45–51,(964,181,176,240)→(893,65,321,437). f79: выход. Порядок карточек важен: последняя перекрывает предыдущие. Замороженные лицо/фон/надпись — утверждённое упрощение.

### MAXOR_IMPACT_CAMERA_ZOOM

Фон со взрывом → полупрозрачные масштабированные копии → RGB-обработка общей сцены. a=interpolate(f,[17,21,73,81],[0,1,1,0]),clamp. Scale=1+2.2a·strength,origin55%30%; RGB-сдвиг5a.10 копий с scale1+(i+1)·0.018·strength,opacity0.035,blur1px. f81: выход к игровому плану. Взрыв — исходный игровой материал, не сгенерированные частицы. Plate содержит обратное масштабирование стоп-кадра взрыва в широкий фон; часть исходного размытия сохранена. При переносе на чистое видео используй собственный материал и проверь силу добавочного размытия. Attribution авторского camera/VFX не доказана исходным проектом.

### MAXOR_BLOCK_FRAME_DEGRADATION

Кадр → смещённые прямоугольные участки → зелёный veil → иллюстративная растровая подпись. Сила=interpolate(f,[4,13,61,62],[0,1,1,0]),clamp. Основной кадр blur3s,contrast1−0.83s,saturate1−0.55s. По сетке40px блоков берутся смещённые участки изображения: ±30s px поx,±20s поy; seed меняется каждые4кадра. Цвет блока#257969 или#1b8877,прозрачность0.9s/0.2s. Veil#2b9b85,opacity0.63s. f62: резкий чистый игровой план. Настоящий codec datamosh не установлен; реализация — визуальная имитация.

## Переиспользование

`GrowingImage`:src,start,end,from,to,exit; прямоугольник каждой оси линейно интерполируется и ограничивается до/после диапазона. `RgbScene`:amount,children; красный и cyan каналы сдвигаются в противоположные стороны, складываются SVG-фильтром. `ImpactZoom`:image,strength(поумолчанию1). `BlockDegradation`:image,block(поумолчанию40px). Последние два включают демонстрационные вход/выход; при интеграции вынеси их в отдельные Sequence и замени локальные материалы. В demo Swap/Pair/Hand заменяй имена файлов и timeline по задаче. Не выдавай вставленный оригинальный effectclip за компонент: здесь вставки и обработка вычисляются отдельно, а source-derived участки — только материалы/контекст.

`staticFile` ожидает материалы вpublic. `Sequence from` обязателен для хвостовых клипов, иначе media time использует кадр всей композиции. SVG RGBfilterid нужно сделать уникальным при нескольких RgbScene в одной композиции. Все вычисления детерминированы по кадру; звук не используется.

## Проверка и достоверность

TypeScript проверен, все пять compositon отрендерены. Duration и fps совпадают с исходными фрагментами. Проверена выборка последовательных кадров движения, полного просмотра каждого кадра не заявляем. Пользователь утвердил после раскрытия ограничений. ChatGPT-проверка не завершена из-за лимита. Inpaint фона под карточками приблизителен; меняй материалы на чистые исходники для production. [Подробности](review.md).
