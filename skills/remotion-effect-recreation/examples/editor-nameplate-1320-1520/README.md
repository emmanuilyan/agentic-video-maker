# Editor Nameplate

Запускаемый Remotion-пример приёма из [видеореференса, 13.20–15.20 с](https://www.youtube.com/watch?v=I6qlhmjkQ44). Сначала меняются картинка слева и объёмная надпись, затем персонаж; после завершения смены весь кадр приближается к персонажу и остаётся приближенным. В демо использованы самостоятельно нарисованные SVG, чтобы проект запускался без исходного ролика.

```bash
npm ci
npm run lint
npx remotion studio src/index.ts
npx remotion render src/index.ts EditorNameplateDemo out/editor-nameplate.mp4
```

- [Компонент](src/EditorNameplate.tsx) принимает три полных кадра состояний и настройки тайминга, фокуса и масштаба.
- [Демо](src/Demo.tsx) показывает три смены за 120 кадров при 60 fps.
- [Рецепт](effect.md) фиксирует порядок слоёв, покадровую схему и параметры.
- [Готовое превью](../../assets/previews/editor-nameplate-1320-1520.mp4) показывает автономное демо.
- `python3 scripts/generate_demo_art.py` заново создаёт SVG для демо.

Для собственного ролика положите в `public/` три изображения 1280×720 с одинаковой геометрией интерфейса. В каждом должен быть свой персонаж, мем слева и заголовок снизу. Компонент меняет нижнюю зону и левую колонку раньше центральной части, затем делает общий зум. Исходные кадры и видео в репозиторий не включены.
