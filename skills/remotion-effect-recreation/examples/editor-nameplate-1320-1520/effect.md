# Editor Nameplate

## Источник и результат

- [Референс](https://www.youtube.com/watch?v=I6qlhmjkQ44): 13.20–15.20 с, без анализа звука.
- Результат: `EditorNameplateDemo`, 1280×720, 60 fps, 120 кадров; [превью](../../assets/previews/editor-nameplate-1320-1520.mp4).
- Реализация: [EditorNameplate.tsx](src/EditorNameplate.tsx), [демо](src/Demo.tsx).
- Пользователь одобрил сравнение v12, в котором зум начинается после смены персонажа, надписи и картинки слева и сохраняет приближённый план.

## Визуальная схема

Три состояния показывают интерфейс редактора персонажа с меняющимся портретом по центру, вставкой слева и широким наклонным объёмным титром снизу. При переходе вставка и титр появляются раньше нового персонажа. Персонаж и фон сменяются коротким размытым перехлёстом. Когда все три элемента обновились, полный кадр быстро приближается вокруг персонажа и остаётся увеличенным до следующей смены.

| Слой сзади вперёд | Содержимое | Положение относительно 1280×720 | Обработка |
| --- | --- | --- | --- |
| Предыдущая сцена | Любой кадр прошлого эпизода | Весь экран | Краткий уход за 2 кадра |
| Состояния 1–3 | Фон, персонаж, интерфейс, вставка и титр в каждом полном кадре | Весь экран; лицо примерно в точке `(0.57W, 0.38H)` | Размытая смена за 6 кадров, затем масштаб до `1.10` |
| Ранняя вставка | Фрагменты изображения следующего состояния | Левая зона `x=0…0.34W, y=0…0.70H` и нижняя полоса `y=0.70…1H` | Маска `polygon`, проявление за 4 кадра до смены персонажа |

В автономном демо левое окно занимает примерно `x=0.02…0.30W`, титр лежит в нижних `0.22H`. Лицевая часть титра светлая с цветной гранью и тёмной нижней экструзией, начертание жирное курсивное со сдвигом примерно `-9°` по оси X. Эти изображения заменяемые: анимационный компонент работает с готовыми кадрами состояний.

## Таймлайн при 60 fps

| Кадры / время от начала | Событие | Формула |
| --- | --- | --- |
| 0–2 / 0–0.033 с | Уходит предыдущий кадр; первая карточка появляется со смещением и размытием | `Y: 24 → -3 → 0 px`, `scale: 0.97 → 1.01 → 1`, `blur: 4 → 1 → 0 px` к кадру 14 |
| 14–17 / 0.233–0.283 с | Первый общий зум | `scale: 1 → 1.10`, затем удержание |
| 23–27 / 0.383–0.450 с | Вставка слева и надпись берутся из второго состояния | `opacity: 0 → 1` через маску левой и нижней зон |
| 27–33 / 0.450–0.550 с | Персонаж и фон переходят во второе состояние | `weights: (1,0) → (0,1)`, пик `blur: 3 px` в середине |
| 33–36 / 0.550–0.600 с | Общий зум второго состояния | `scale: 1 → 1.10`, затем удержание |
| 47–51 / 0.783–0.850 с | Вставка и надпись берутся из третьего состояния | Тот же масочный подъём |
| 51–57 / 0.850–0.950 с | Персонаж и фон переходят в третье состояние | Тот же размытый перехлёст |
| 57–60 / 0.950–1.000 с | Общий зум третьего состояния | `scale: 1 → 1.10`, затем удержание до конца |

## Параметры и повторение

`scenes` — обязательные три полных изображения одного размера; `previousScene` — необязательный начальный кадр. `switchFrames=[27,51]` задаёт начало смен персонажа. `leadFrames=4` запускает левую вставку и титр заранее; `transitionFrames=6` определяет длину размытого перехлёста. `initialSettleFrame=14`, `zoomFrames=3`, `zoomScale=1.1` задают зум без обратного отъезда. `focusX=0.57`, `focusY=0.38` — нормализованная опорная точка вблизи лица. Кадры рассчитаны на 60 fps; при иной частоте пересчитайте их пропорционально.

```tsx
<EditorNameplate
  frame={useCurrentFrame()}
  scenes={["first.png", "second.png", "third.png"]}
  previousScene="before.png"
  focusX={0.57}
  focusY={0.38}
/>
```

Положите полные кадры состояний в `public/`, сохранив положение интерфейса. Ранняя маска должна выбирать левую колонку и нижний титр; остальную часть кадра переключайте позднее. Масштаб применяйте к персонажу вместе с окружающим фоном, с `transform-origin` у лица. Интерполируйте масштаб от `1` до `1.10` и зафиксируйте конечное значение. Демонстрационные SVG можно пересоздать командой `python3 scripts/generate_demo_art.py`.

## Проверка и ограничения

Оригинальный ролик сравнивался с утверждённым локальным v12. Рендер в Git показывает ту же последовательность и заменяемую самостоятельно нарисованную графику; исходное видео и его кадры не включены. Проект проверен `npm run lint` и полным рендером `EditorNameplateDemo`.
