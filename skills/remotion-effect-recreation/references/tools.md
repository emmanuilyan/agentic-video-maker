# Инструменты для разбора эффекта

[`scripts/effect_tools.py`](../scripts/effect_tools.py) использует только стандартную библиотеку Python, `ffmpeg` и `ffprobe`. Передай ему локальный видеофайл; для общедоступной ссылки сначала получи файл доступным загрузчиком, например `yt-dlp`. Команды не изменяют исходник.

## Покадровый разбор

```bash
python3 scripts/effect_tools.py frames reference.mp4 \
  --start 13.5 --end 15.5 --out analysis/reference
```

Скрипт сохраняет все кадры участка, `frames.json` с **исходными PTS** каждого кадра и обзорный `contact-sheet.jpg` (до 32 кадров). Пользуйся точными временами из JSON, если начало эффекта приходится между округлёнными секундами. Для длительных участков выбирай узкий диапазон, чтобы не заполнять диск сотнями кадров.

## Цвет и граница раскрытия

```bash
python3 scripts/effect_tools.py color reference.mp4 \
  --time 15.3 --rect 134,286,306,54

python3 scripts/effect_tools.py track reference.mp4 \
  --start 14 --end 15.5 --rect 125,280,325,65 \
  --band 286:313 --band 314:341 \
  --color '#E8D943' --tolerance 45 --out analysis/highlight-edges.json
```

`color` находит медиану ярких насыщенных пикселей внутри выбранного прямоугольника. Выбирай область так, чтобы в ней преобладал нужный цвет. `track` показывает границы пикселей, близких к указанному RGB, отдельно для каждой горизонтальной полосы. `--tolerance` — максимальная разница **по каждому каналу**. Пустая граница означает, что подходящих пикселей на кадре нет. Если в области есть другие предметы того же цвета, сузь `--rect` или раздели её на `--band`.

## Сверка с рендером

```bash
python3 scripts/effect_tools.py compare reference.mp4 out/effect.mp4 \
  --render-zero-at 13.5 \
  --times 14.14,14.38,14.63,15.33 \
  --rect 105,215,410,150 --out analysis/comparison
```

`--render-zero-at` задаёт момент оригинала, который соответствует нулевому кадру Remotion. Каждый PNG содержит исходный кадр слева и рендер справа. Область обрезки задаётся в координатах кадра `x,y,width,height`; если её опустить, размер обоих видео должен совпадать. Сравнивай также короткий движущийся фрагмент: отдельные кадры не выявляют рывки между ними.
