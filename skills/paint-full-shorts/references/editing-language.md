# Editing language

Choose the operation from what the story means. These are options, not a checklist for every video.

| Operation | Story use | Visual evidence |
|---|---|---|
| Lasso / magic wand | Identify a subject or important detail | Tool selection, target contact, fitted marching ants |
| Free Transform | Magnify importance, compare scale, move a cutout | Shortcut or tool activation; handle, cursor and object move together |
| Eye / group visibility | Reveal a hidden fact, switch before/after, set up a punchline | Click eye; layer row and canvas change on the same frame |
| Reorder layers | Explain depth, priority or something hidden behind another object | Row drags through stack; canvas occlusion follows the same ordering |
| Brush mask | Reveal a new place, era, image or evidence | Mask coverage follows the visible brush tip |
| Eraser | Remove an obstacle, erase a misconception, uncover a layer below | Erased trail corresponds to tool width and path |
| Duplicate / clone | Multiplication, repetition, scale of a problem | New instance and row share an event; each copy has deliberate spacing |
| Eyedropper + fill | Transfer a property, recolor a world, switch mood | Sample changes foreground swatch; fill changes the intended region |
| Text tool | Introduce a thesis, fact or final title | Tool click, insertion point, character steps, text layer |
| Curves / Hue-Saturation | Reveal night/day or a change of state | One control drives the actual tonal/color response |
| History / Undo | Correct a mistake or execute a visual joke | Return to an earlier document state and matching history entry |
| Zoom / Hand | Discover a detail or move between related ideas | Stable chrome; one canvas camera; cursor contacts transform with it |
| Crop | Remove context, focus on a detail, reshape composition | Crop boundary, commit, updated viewport |
| Save / export | End a short with a completed artifact | Brief save state or file name update; hold the finished canvas |

## Useful short structures

**Five seconds:** subject already visible → select → transform → reveal a prepared group → title/commit → one-second hold. If this feels rushed, combine selection with the initial state and use only three edits.

**Ten to fifteen seconds:** ordinary object → selection exposes a detail → duplicate or transform explains the scale → a mask reveals the contrast → commit a conclusion.

**Narrated explanation:** map each measured clause to a single document operation. Stay on the existing canvas between phrases. Introduce a new document only when the story moves to a distinct topic.

**Undo joke:** establish a readable normal state → one edit makes it absurd → hold the consequence → Undo → final return or second twist. The joke requires the intermediate state to remain readable.

## Pace and design

Treat the editor as a visible cause of the montage, not as tiny decorative chrome around independent animation. Use a restrained palette in the shell and bold color on the canvas. Small tool labels add authenticity; essential meaning comes from the large object, gesture and short copy.

Limit simultaneous palettes. Open a dialog only for a beat that needs it, then close or collapse it. Preserve the final result long enough to read. For a loop, reverse or return the document deliberately; an abrupt export-to-start jump is not inherently seamless.
