# Typography Editor

Создавай выразительные надписи, связывая наблюдения в референсе с конкретной гарнитурой, движением и временем чтения. Сохраняй исходный текст и порядок слов; согласованные исправления фиксируй явно.

## Выбери задачу

- **Разбор:** измерь надписи, опиши форму букв и эффекты, сохрани таблицу с доказательствами. Сам разбор не требует создания видео.
- **Создание или правка:** используй текущий проект, текст и параметры пользователя. Для Remotion прочитай [процесс реализации](references/remotion-workflow.md).
- **Наше хаотичное направление:** используй каталог [R1 — Max0r](references/max0r.md) и [R2 — первые 16 секунд Remix](references/remix-intro.md). Прочитай обе таблицы; изображения открывай для выбранных приёмов.

При запросе «как раньше», «рандомно», «по нашим референсам» выбирай непредсказуемые оформления без повторов. Явный новый бриф определяет стиль: например, спокойные брендовые субтитры могут использовать одну гарнитуру. Длительность 5 секунд, вертикальный кадр и накопление текста относятся к исходному тесту, а не ко всем задачам навыка.

## Разбери доказательства

Для нового источника проверь доступный видеофайл, фактические fps и разрешение. Расширение `.crdownload` не доказывает ни готовность, ни непригодность: проверь декодирование нужного участка, не переименовывай активную загрузку. URL без просмотренных кадров не подтверждает внешний вид.

Сначала просмотри нужный отрезок обзорно, затем проверь выбранные переходы по кадрам и PTS. Записывай отдельно:

`источник / версия файла / интервал / точность / текст / форма шрифта / заливка и контур / движение / фон / начало читаемого состояния`.

Различай длительность фразы, оформления, цветовой фазы и эффекта фона. Граница запрошенного участка может обрезать продолжающийся титр. Неизвестный шрифт описывай по форме; названия похожих гарнитур отмечай как аналоги. Проверяй кириллицу выбранного файла.

## Выбери оформления без повторов

Единица выбора — фрагмент текста или новое оформление уже видимой фразы. Каждая единица получает `fonts[]`, `motionFamily`, `treatmentFamily`, `layout`, `source` и фиксированный `seed`.

1. Разбей текст на смысловые группы, сохраняя слова и пунктуацию.
2. Перемешай варианты с фиксированным seed; выбирай без возвращения.
3. Исключай использованные гарнитуры и семейства движения/оформления. Две гарнитуры внутри одной подписи расходуют обе. Смена веса, цвета или ID сама по себе не создаёт новый стиль.
4. Сравни видимое действие: вращение знаков и вращение строки родственны; масштабный удар и пружинный штамп могут повторять одну пластику. Измени движение или замени вариант.
5. После каждой замены сравни новый вариант со всеми оставшимися. Например, брызги позади перехода «контур → заливка» не устраняют сходство с уже выбранной прорисовкой и заполнением букв. Затем чередуй силуэты и композиции. При нехватке вариантов укрупни группы или создай новые; не запускай набор по кругу.

Копии и колебания внутри одного эффекта допустимы. Повторное назначение того же решения другой подписи нарушает запрет. Сходные семейства отмечены в каталогах.

## Проверь и выдай

Сначала проверь текст, тайминг чтения и визуальную уникальность, затем результат рендера. **0,24 с смены шрифта на уже прочитанном имени не задают время чтения новой фразы.** Если заданный хронометраж тесен, сохраняй читаемые группы между сменами и явно оцени результат.

Для видео выдай проверенный файл и исходник; для разбора — таблицу с источниками и таймкодами. Укажи существенные ограничения. Называй новый рецепт реализованным только после создания и проверки его компонента. Подробный критерий готовности — в [процессе Remotion](references/remotion-workflow.md).
