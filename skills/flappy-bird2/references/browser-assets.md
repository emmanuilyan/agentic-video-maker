# Обычный ChatGPT: ресерч и графика

## Рабочий маршрут

Использовать подключённый браузер через поддерживаемые UI-инструменты. Найти подходящий существующий диалог, проверить видимый выбранный режим **«Чат»**, а не «Работа». Тип записи chatgpt сам по себе режима не доказывает. Не создавать Codex/Work-задачу ради подготовки. Новый постоянный диалог создавать только по явному запросу; если подходящего нет, использовать временный чат или подготовить бриф для переноса.

Отправлять короткий самостоятельный бриф: цель, необходимый контекст, ограничения, результат. Ресерч нужен для содержательно сложной темы; простую геометрию решать локально. Не повторять полученный ресерч в Codex: проверить ключевые факты и выбранные материалы. Не обещать экономию лимита без измерений.

Личные/клиентские файлы загружать только в разрешённом пользователем объёме. Обычно достаточно описания предмета. Сохранить финальный запрос, ответ и URL при доступности. ChatGPT сам не является первоисточником фактов.

Если браузер отсутствует или нужен вход: сообщить блокер, подготовить один готовый бриф, продолжить базу/локальную проверку. Не обходить вход через cookies, скрытые API или неподдерживаемую автоматизацию. Не заменять браузерную генерацию другим провайдером молча.

## Художественный язык

До тем зафиксировать art bible: вид сбоку, герой вправо, перспектива, плотность деталей, палитра, свет, контур, размеры, pivot героя и anchors препятствий. Разные предметы выглядят частями одной игры. Pixel art удобен по умолчанию; другой цельный стиль допустим.

| Семейство | Требование |
|---|---|
| Герой | RGBA cutout, одинаковые корпус и pivot в 3 позах; можно отдельными файлами |
| Верх/низ препятствия | отдельные прозрачные элементы, понятная внутренняя кромка |
| Фон | opaque, без запечённых героя, ворот, HUD/текста; спокойная игровая зона |
| Параллакс/земля | отдельный горизонтально повторяемый слой с проверенным швом |
| Декорации/VFX | прозрачные cutout, различимы с твёрдыми препятствиями |

Полный кадр игры — moodboard, а не замена раздельных ассетов. Смена темы обычно требует героя, препятствий и окружения.

## Бриф для сложного ресерча

    Готовим тему игры в вертикальном ролике.
    Тема/смысл: [кратко, без приватных исходников].
    Герой летит вправо через верхние/нижние препятствия.
    Нужны 3 ассоциации, герой, препятствия, фон; факты,
    которые нельзя исказить; прямые первоисточники.
    До 500 слов. Отдели факты от творческих предложений.
    Не создавай Work-задачи. Без большого кода и дневника.

## Бриф для генерации

    Создай изображение для оригинальной 2D-игры.
    Семейство: [один герой / препятствие / фон]. Тема: [смысл].
    Общий стиль: [art bible]. Камера строго сбоку.
    Герой направо, полный силуэт, одинаковые пропорции в позах,
    пустые промежутки, истинный прозрачный RGBA фон.
    Игровой canvas: [W×H], pivot: [описание опорной точки].
    Это исходник, точный атлас будет собран кодом.
    Без текста, сетки, логотипов, водяных знаков и чужих спрайтов.
    Создай само изображение, не только описание.

Для фона заменить требования cutout на opaque. Не просить прозрачность и полноценное небо в одном запросе. Не копировать Flappy Bird sprites/branding. Референс предыдущей темы загружать при имеющейся авторизации для файла.

## Получение и проверка

Дождаться самого изображения. Скачать исходник штатной кнопкой/download или page-assets. Скриншот интерфейса — свидетельство предпросмотра, не финальный ассет. Проверить локальный файл и открыть его.

Проверить формат, размер, alpha, полный силуэт, отсутствие нарисованной шахматки/текста. Сопоставить центр корпуса, масштаб, направление и пропорции поз. Для тайла проверить горизонтальный стык. Сложный лист разбить на отдельные запросы.

Оригинал хранить неизменным. Нормализация: кроп, размер, canvas, выравнивание корпуса по pivot, atlas, хеши. Pixel art — nearest-neighbor. Не растягивать позы независимо по собственным bounding boxes: корпус начнёт пульсировать. Неправильную геометрию/фон исправлять редактированием или перегенерацией через выбранный браузерный маршрут.

Ledger: id, role, theme, prompt, conversationUrl, видимая модель либо unknown, sourcePath/sourceSha256, normalizedPath/normalizedSha256, transforms, canvas, pivot/anchor, alphaCheck, reviewStatus, provenance, rightsStatus. Сгенерированное происхождение не равно юридической очистке.

Заглушки допустимы для проверки механики. Если финальная графика недоступна, сдавать обозначенную пробу с ограничением, а не заявлять готовность художественного пакета.
