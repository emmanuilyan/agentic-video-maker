# Cinematic Typography

## Overview

Воспроизводи референс как измеряемую систему, а не как набор эпитетов. Сначала отделяй наблюдаемое от предположений; затем сохраняй неподвижный силуэт букв и анимируй только внутреннюю эрозию.

## 1. Разбери референс

1. Проверь разрешение, fps и длительность. Просмотри общий монтаж, затем плотное окно кадров одной и той же надписи.
2. Запиши для репрезентативных карточек: таймкод, текст, bounding box, высоту прописных, цвет внутренних пикселей, число строк, выравнивание и положение относительно лица.
3. Сравни несколько соседних кадров. Если контур букв неподвижен, а внутренние тёмные выемки меняются, это анимированная маска внутри текста, а не пыль поверх кадра.
4. Маркируй каждый вывод как `наблюдение`, `измерение` или `адаптация`. Не называй шрифт точным без метаданных проекта или файла шрифта.

Для стиля из референсного военного Short обязательно прочитай [измеренный рецепт](references/style-recipe.md).

## 2. Собери оформление

- Выбирай шрифт по силуэту кириллических глифов и фактической cap-height, а не по названию или CSS `font-size`.
- Масштабируй параметры через короткую сторону кадра: `s = min(width, height) / 720`.
- Размещай карточку в свободном пространстве конкретного плана. Во время поэтапного появления строк сохраняй один якорь.
- Выделяй цветом или размером только смысловой удар. Не превращай каждое слово в отдельный стиль.
- Не добавляй жирную обводку по умолчанию. Для отделения от фона достаточно тонкого тёмного края или тени.

Если создаёшь или меняешь проект, сначала покажи пользователю измерения, допущения и предлагаемый рецепт и получи approval; повторно не спрашивай, если создание или дизайн уже явно одобрены.

## 3. Реализуй движение

Для Remotion прочитай [детерминированную реализацию](references/remotion.md). Для другого редактора перенеси те же инварианты: две размерности дефектов, клип внутри альфы текста, ступенчатое обновление около 8–12 fps и неизменная геометрия глифов.

Не используй случайность, зависящую от времени запуска. Seed должен зависеть только от идентификатора карточки, номера квантизованной фазы и индекса дефекта.

## 4. Проверь результат

Рендери минимум три соседних кадра одной удерживаемой карточки и один кадр на каждом монтажном плане.

**PASS**, если:

- силуэт и переносы не прыгают;
- внутренняя текстура заметно меняется, но слово читается с первого взгляда;
- дефекты не выходят за альфу букв;
- лицо, глаза и важное действие не перекрыты;
- цвет, cap-height и ширина блока попадают в допуск рецепта;
- коммерческий шрифт не скопирован в проект без лицензии.

## Quick Reference

| Задача | Решение |
|---|---|
| Точный шрифт неизвестен | Назови ближайший проверенный аналог и уверенность |
| Вертикальный или широкий кадр | Масштабируй от короткой стороны, затем выбери свободную область |
| «Живая грязь» | Обновляй внутреннюю маску ступенчато, не двигай контур |
| Плохая читаемость | Сначала уменьши эрозию, затем добавь тонкую тень |
| Длинная фраза | Перекомпонуй до двух строк; не ужимай буквы бесконечно |

## Common Mistakes

- Выдавать Impact, Druk или Bebas за доказанный исходный шрифт.
- Масштабировать квадратный референс по высоте вертикального кадра и получать огромный текст.
- Делать одноразовое накопление частиц вместо постоянного нерегулярного мерцания.
- Накладывать грязь поверх прямоугольника, а не вычитать её из текста.
- Компенсировать слабый контраст обводкой 10–12 px.
- Писать «как в референсе» без покадрового сравнения.
