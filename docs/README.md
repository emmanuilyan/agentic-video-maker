# Индекс справочников

Эти тематические Markdown-файлы дополняют самостоятельные skills. Открывай нужные разделы по мере работы; читать всю базу целиком для каждого ролика не требуется.

Общий критерий для PNG-превью результата описан в [`png-delivery.md`](png-delivery.md).
Необязательная внешняя проверка готового ролика и готовый промпт для браузерного ChatGPT — в [`chatgpt-video-review.md`](chatgpt-video-review.md).

## Stop-motion

Сначала открой [`README.md`](stop-motion/README.md), затем выбери модуль по текущему этапу:

- контракт и рабочие этапы — `01_SCOPE_AND_WORKFLOW.md`;
- исследование и разбор референсов — `02_SOURCE_RESEARCH.md`, `03_REFERENCE_DECOMPOSITION.md`;
- план сцены и движения — `04_SCENE_BLUEPRINT.md`, `05_MOTION_PLANNING.md`;
- покадровая реализация и временная непрерывность — `06_FRAME_EXECUTION.md`, `07_TEMPORAL_CONTINUITY.md`;
- контроль качества и координация — `08_QUALITY_CONTROL.md`, `09_AGENT_ORCHESTRATION.md`;
- пример, библиотека источников и глоссарий — `10_WORKED_EXAMPLE.md`, `11_SOURCE_LIBRARY.md`, `12_GLOSSARY.md`.

`STOPMOTION_AGENT_MANUAL.md` объединяет модули для последовательного чтения. Тематические модули — первичный источник при обновлении.
