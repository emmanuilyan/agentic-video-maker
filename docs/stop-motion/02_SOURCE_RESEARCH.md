# 02. Поиск исходников и референсов

## Цель

Собрать не случайную подборку картинок, а набор источников, который отвечает на конкретные производственные вопросы:

- как движется объект;
- как действие распадается на фазы;
- как ведёт себя материал;
- как выглядит контакт с поверхностью;
- какой ракурс делает действие читаемым;
- какие визуальные элементы можно использовать напрямую;
- какие материалы служат только внутренним референсом.

## 1. Различай четыре режима использования

| Режим | Что происходит | Что обязан сделать агент |
|---|---|---|
| Наблюдение | Источник используется для понимания движения, материала или композиции | Зафиксировать автора, ссылку и конкретное наблюдение |
| Синтез | Несколько источников превращаются в новое решение | Показать, какие свойства взяты из каждого источника |
| Цитирование | Фрагмент показывается или упоминается в готовом материале | Проверить допустимость цитирования и указать источник |
| Прямое использование | Изображение, видео, текстура или звук входит в результат | Проверить лицензию, ограничения, атрибуцию и коммерческую совместимость |

Наличие источника в открытом интернете не означает разрешение на прямое использование.

## 2. Семь классов референсов

### A. Референс идентичности

Показывает стабильную форму, цвет, пропорции, маркировку и фактуру главного объекта. Лучше иметь:

- общий вид;
- вид сбоку;
- вид сверху или в три четверти;
- крупный план характерной детали.

### B. Референс движения

Показывает действие целиком во времени. Предпочтительны:

- видео со стабильной камерой;
- slow motion;
- хронографическая последовательность;
- анимационный тест;
- making-of с черновым блокингом;
- несколько ракурсов одного действия.

### C. Референс физики

Отвечает на вопросы о массе, трении, инерции, деформации и контакте. Он может отличаться по внешнему виду от финального объекта, если физические свойства сопоставимы.

### D. Референс материала

Показывает фактуру, характер блика, складки, края, прозрачность, зерно и реакцию на деформацию.

### E. Референс постановки

Показывает композицию, свободное место перед движением, высоту камеры, силуэт и взаимное расположение объектов.

### F. Референс техники

Показывает, как профессиональный аниматор решает похожую задачу: каденцию, удержания, блокинг, смену поз, controlled imperfection.

### G. Прямой исходник

Конкретный файл, который войдёт в результат. Для него обязательны данные о происхождении и правах.

## 3. Правильная последовательность поиска

Ищи в таком порядке:

1. **Реальное движение.** Сначала пойми механику без стилизации.
2. **Материал и контакт.** Найди поведение похожей массы и поверхности.
3. **Stop-motion-прецедент.** Посмотри, как реальное движение упрощают и акцентируют.
4. **Композиция и камера.** Выбери ракурс, в котором фазы не перекрывают друг друга.
5. **Художественная фактура.** Определи внешний вид только после понимания движения.
6. **Легальные исходники.** Если нужны готовые элементы, найди версии с совместимыми правами.

Поиск только по словам `beautiful stop motion style` создаёт мудборд, но не даёт данных для анимации.

## 4. Декомпозиция запроса перед поиском

Для каждого действия выпиши:

- субъект;
- основной глагол;
- подготовительную фазу;
- момент приложения силы;
- фазу максимальной скорости;
- смену направления;
- контакт;
- реакцию;
- затухание;
- материал;
- поверхность;
- нужный ракурс.

Для сцены с бумажным самолётиком список выглядит так:

- бумажный самолёт;
- разгон;
- небольшой наклон назад перед стартом;
- отрыв от стола;
- восходящая дуга;
- вершина полёта;
- снижение;
- касание носом или нижним ребром;
- короткий прогиб крыльев;
- один небольшой отскок;
- остановка;
- матовая бумага;
- гладкий белый стол;
- боковой ракурс.

## 5. Грамматика поискового запроса

Базовая формула на английском:

`subject + action + phase + view + temporal modifier + reference type`

Рабочие примеры:

- `paper airplane takeoff side view slow motion`
- `paper airplane landing contact side view high speed`
- `paper plane glide arc profile reference`
- `paper flex impact slow motion`
- `object jump over obstacle stop motion blocking`
- `stop motion paper animation behind the scenes`
- `stop motion object animation key poses`
- `stop frame animation timing spacing demonstration`
- `paper airplane shadow landing reference`
- `paper texture matte studio soft light`
- `live action reference object jump animation`
- `animation blocking contact pose overshoot settle`

Русские запросы полезны для локальных материалов, но профессиональная терминология чаще лучше индексируется по-английски:

- `покадровая анимация движение по дуге`;
- `стоп моушен тайминг и спейсинг`;
- `референс приземления предмета замедленная съёмка`;
- `фазы прыжка вид сбоку`;
- `покадровая анимация удержание позы`;
- `раскадровка движения предмета через препятствие`.

## 6. Поиск по фазам, а не только по действию

Один ролик редко показывает всё идеально. Ищи отдельно:

- `takeoff anticipation`;
- `airborne apex`;
- `landing contact`;
- `impact recoil`;
- `settle motion`;
- `wing flex`;
- `sliding friction stop`.

Затем синтезируй согласованную последовательность. Не склеивай механически несовместимые фазы от объектов разной массы.

## 7. Поиск профессиональных источников

Добавляй к запросам:

- `official`;
- `academy`;
- `masterclass`;
- `lecture`;
- `making of`;
- `behind the scenes`;
- `animation test`;
- `blocking pass`;
- `animator breakdown`;
- `production diary`;
- `case study`;
- `paper`;
- `thesis`;
- `site:disneyanimation.com`;
- `site:aardman.com`;
- `site:nfb.ca`;
- `site:animationmentor.com`;
- `site:routledge.com`;
- `site:loc.gov`;
- `site:si.edu`;
- `site:metmuseum.org`.

Для научных работ используй сочетания:

- `stop-motion temporal coherence`;
- `stop-motion motion blur perception`;
- `stop-frame animation materiality`;
- `animation timing spacing perception`;
- `chronophotography locomotion`;
- `kinetic sculpture stop-motion`;
- `animation temporal noise`.

## 8. Иерархия доверия

### Уровень 1 — первичные и институциональные источники

- официальный материал студии;
- интервью непосредственного участника производства;
- книга практикующего аниматора;
- университетская публикация;
- музейный или государственный архив;
- фильм и making-of от правообладателя.

### Уровень 2 — профессиональное образование

- признанная школа анимации;
- лекция профессионального аниматора;
- подробный разбор с демонстрацией кадров;
- отраслевое издание с именованным автором.

### Уровень 3 — качественная вторичная практика

- блог работающего специалиста;
- портфолио с process breakdown;
- профессиональный форум с проверяемыми примерами.

### Уровень 4 — материал только для навигации

- агрегаторы;
- Pinterest;
- безымянные подборки;
- SEO-статьи;
- короткие советы без демонстрации;
- перезаливы.

Источник четвёртого уровня может подсказать имя автора или название фильма, но не должен быть конечной опорой.

## 9. Оценка качества конкретного референса

Поставь по каждому критерию от 0 до 2 баллов.

| Критерий | 0 | 1 | 2 |
|---|---|---|---|
| Релевантность действия | Другое действие | Частично похоже | Та же механика |
| Полнота фаз | Один момент | Несколько фаз | Полный цикл |
| Читаемость | Сильные перекрытия | Приемлемо | Чёткий силуэт и контакты |
| Совпадение ракурса | Неприменимый | Можно адаптировать | Подходит напрямую |
| Совпадение массы и материала | Иная физика | Частично похоже | Очень близко |
| Происхождение | Неизвестно | Вторичный источник | Первичный источник |

Используй как основную опору источник с результатом не ниже 9 из 12. Более слабый материал допустим только для отдельной детали.

## 10. Правило двух независимых свидетельств

Для важного свойства движения найди минимум два источника. Особенно для:

- траектории;
- порядка контактов;
- длительности реакции;
- поведения материала;
- анатомии;
- необычного механизма.

Если источники расходятся, не усредняй автоматически. Проверь различия в скорости, массе, поверхности, угле камеры и стилизации.

## 11. Как работать с видео

Для каждого полезного участка зафиксируй:

- точный URL;
- автора или организацию;
- название;
- таймкод начала и конца;
- ракурс;
- скорость воспроизведения, если известна;
- видимые ключевые фазы;
- что закрыто или не читается;
- что переносится в текущую сцену;
- что не переносится.

Не записывай «полезное видео про прыжок». Записывай конкретно:

> На участке 00:18–00:22 виден боковой профиль: перед отрывом нос опускается, максимальный вертикальный подъём наступает после прохождения половины горизонтальной дистанции, перед контактом угол атаки уменьшается.

## 12. Как извлекать кадры без потери контекста

Выдели:

1. стартовую позу;
2. последнюю позу перед началом;
3. первый кадр явного движения;
4. максимальное растяжение или отклонение;
5. последний контакт перед отрывом;
6. первый кадр без контакта;
7. вершину дуги;
8. последний кадр перед новым контактом;
9. кадр контакта;
10. максимальную реакцию после удара;
11. начало затухания;
12. окончательную позу.

Сохраняй порядок и временные интервалы. Набор красивых стоп-кадров без временной шкалы не является референсом движения.

## 13. Разрешения и происхождение

### Для внутреннего референса

Сохраняй ссылку и автора. Не распространяй исходник как часть пакета, если нет разрешения.

### Для прямого использования

Проверь:

- указан ли правообладатель;
- есть ли явная лицензия;
- разрешены ли изменения;
- разрешено ли коммерческое использование;
- требуется ли та же лицензия для производного материала;
- нужна ли атрибуция;
- есть ли ограничения по личности, товарным знакам, музейным правилам или юрисдикции.

### Практическое правило для коммерческого ролика

Предпочитай:

1. собственные материалы;
2. материалы, предоставленные заказчиком с подтверждёнными правами;
3. public domain или CC0;
4. CC BY при корректной атрибуции;
5. CC BY-SA только после проверки совместимости всего результата.

Не используй для изменённого коммерческого ролика материалы с `ND`. Материалы с `NC` не считай автоматически совместимыми с монетизируемым YouTube-каналом.

Юридические вопросы зависят от юрисдикции; агент фиксирует данные, но не выдаёт окончательное юридическое заключение.

## 14. Минимальная запись об исходнике

Для каждого источника храни:

| Поле | Содержание |
|---|---|
| ID | Короткий стабильный код |
| Название | Оригинальное название страницы, фильма или файла |
| Автор | Создатель или организация |
| URL | Прямая страница первоисточника |
| Дата доступа | Календарная дата |
| Тип | Видео, серия кадров, статья, книга, изображение, архив |
| Режим | Наблюдение, синтез, цитирование или прямое использование |
| Права | Лицензия или статус, записанные дословно |
| Полезный участок | Таймкод, страницы или конкретные изображения |
| Наблюдения | Только то, что подтверждается источником |
| Решение | Как данные будут адаптированы |
| Ограничения | Что нельзя переносить или что остаётся неясным |

## 15. Критерий остановки поиска

Поиск завершён, когда есть:

- два качественных референса полного движения;
- отдельный референс самого сложного контакта;
- референс материала;
- референс композиции;
- достаточная информация для стартовой, ключевых и конечной поз;
- ясный статус каждого прямого исходника;
- отсутствие нерешённых противоречий, влияющих на движение.

Дополнительные двадцать картинок не улучшают решение, если они не отвечают на новый вопрос.

## 16. Антипаттерны

Не делай так:

- искать только название объекта;
- собирать десятки эстетически похожих изображений без движения;
- использовать одну GIF-анимацию без автора;
- оценивать скорость по ролику с неизвестным замедлением;
- копировать контакт из другого ракурса без пространственной реконструкции;
- путать референс материала с референсом физики;
- считать популярность источника признаком точности;
- сохранять только поисковую миниатюру;
- терять URL первоисточника;
- использовать чужую работу напрямую, потому что она «сильно изменена нейросетью».
