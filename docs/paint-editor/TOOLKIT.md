# Переиспользуемые инструменты Paint Full Shorts

Библиотека находится в `src/paint-full`; её независимая копия входит в skill `paint-full-shorts`. Она не привязана к планете или конкретному сценарию.

| Блок | Что готово |
|---|---|
| Ретро-редактор | Окно, меню, линейки, панель инструментов; отдельные слоты для холста, настроек и подписей |
| Прозрачный холст | Шахматная подложка автоматически видна без фонового слоя, вокруг вырезанных объектов и в стёртых участках |
| Курсор | Перелёты, паузы, нажатия, следование ручке или кисти; стрелка, текст, кисть и ластик |
| Выделение | Бегущая обводка по любому заданному SVG-контуру |
| Трансформация | Восемь ручек; перетаскивание за любой угол; связанные пропорции или независимые W/H; поддержка повёрнутого объекта |
| Размер холста | W/H в пикселях, 9:16 / 1:1 / 16:9 / 4:5 / 4:3 и свои пропорции; сохранить размер содержимого, вписать, заполнить с обрезкой или растянуть; Undo/Redo |
| Кисть / ластик | Общий путь для наконечника и маски; несколько мазков; результат сохраняется |
| Текст | Печать по таймкодам с поддержкой кириллицы, emoji и составных символов |
| Слои и история | Общие данные для холста и палитры; группы, видимость, порядок, дубликаты, Undo/Redo |

В Remotion Studio есть четыре композиции: `PaintFullShorts` — исходное демо на общей библиотеке, `ToolkitChecks` — наглядные примеры инструментов, `TransparencyCheck` — скрытие фонового слоя и стирание в прозрачность, `SizingCheck` — смена пропорций холста внутри вертикального редактора.

Для следующего проекта:

```bash
node /Users/mac/.codex/skills/paint-full-shorts/scripts/install-toolkit.mjs /absolute/remotion-project
```

Инструменты копируются в `src/paint-full`. Существующие файлы установщик не перезаписывает. После копирования сценарий задаёт ассеты, текст, координаты и кадры событий.

Подробные примеры API: [toolkit.md](/Users/mac/.codex/skills/paint-full-shorts/references/toolkit.md).

Следующая полезная очередь: пипетка + заливка, инструмент Crop с рамкой, Hue/Saturation и диалог сохранения. Они ещё не реализованы; перечисленные в таблице блоки уже работают.
