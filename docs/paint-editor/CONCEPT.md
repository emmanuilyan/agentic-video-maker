# Paint Full Shorts

Весь short происходит внутри ретро-графического редактора. Монтаж становится видимым действием: зритель видит инструмент, контакт и результат. Серые панели, синий заголовок окна, линейки и курсор дают узнаваемую оболочку Photoshop конца 1990-х; сам холст остаётся крупным и выразительным.

## Монтажный язык

| Приём | Что делает в истории | Реализация в Remotion |
|---|---|---|
| Лассо / волшебная палочка | Выбирает героя, находит важную деталь | SVG-контур, штриховая обводка с покадровым смещением |
| Free Transform | Увеличивает значение, меняет масштаб | Общая геометрия объекта, рамки, ручек и курсора |
| Видимость слоя | Даёт контраст до/после, открывает скрытый факт | Состояние слоя и значка глаза от одного cue |
| Перестановка слоёв | Показывает, кто выше / кто за чем | Одна модель порядка для палитры и z-index |
| Маска кистью | Открывает фото, эпоху или вторую половину сцены | SVG mask; путь мазка совпадает с наконечником |
| Ластик | Убирает миф, препятствие или лишнюю деталь | Инвертированная маска по пути курсора |
| Дублирование | Показывает рост количества или повторение | Экземпляры одного ассета с явными координатами |
| Пипетка + заливка | Перекрашивает мир, переключает настроение | Взятый цвет сначала в образце, затем в области |
| Текстовый инструмент | Добавляет тезис или кульминацию | Покадровая печать, каретка, новый текстовый слой |
| Curves / Hue-Saturation | Меняет время суток или состояние | Положение контролов и цвет изображения связаны |
| History / Undo | Возвращает ошибку, строит шутку | Возврат предыдущего снимка состояния документа |
| Zoom / Hand | Переводит внимание между деталями | Камера внутри холста; панели остаются на месте |

## Демо: «Маленький объект → свой мир»

0–1 с: выделить планету. 1–2 с: растянуть за угол. 2–2,75 с: включить группу «Космос». 2,75–4 с: напечатать «СВОЙ МИР». 4–5 с: удержать готовый постер.

Демо без диктора: слышны щелчки, перетаскивание, клавиши и подтверждение. Подписи обозначают действия. Для полноценного сюжетного ролика действия привязываются к измеренным фразам озвучки.

## Редактирование

`npm install`, `npm run audio`, `npm run studio`; финальный MP4 — `npm run render`. Все события в `src/timeline.json`, тексты в `src/copy.ts`, геометрия — в `src/document.ts`. Настройка браузера по умолчанию использует Remotion; локальный путь можно передать через `REMOTION_BROWSER_EXECUTABLE`.

Техническая опора: [Remotion CLI render](https://www.remotion.dev/docs/cli/render). Интерфейс и иллюстрации созданы для этого демо; внешние медиа не использованы.
