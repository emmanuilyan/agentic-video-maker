Утверждено пользователем 2026-10-26: «супер, сохраняй». Сохранён точный рендер v4, показанный справа в финальном сравнении; повторный рендер после утверждения не выполнялся.

Источник: https://www.youtube.com/watch?v=I6qlhmjkQ44, 846.70–847.90 (14:06.70–14:07.90). 1280×720, 60fps, 72 кадра. Звук не используется.

## Слои и кадры

1. Цветной вводный стоп-кадр846.7 до кадра4.
2. Обесцвеченная игровая подложка847.0; отдельный слой исходных красных пикселей поверх неё.
3. Кадры12–30: растворение в более позднюю позу847.2, где кровь видна на обеих руках и всём торсе. У исходника титр проходит за телом: тело сохранено целиком, окружающие буквы/фон восстановлены ранним чистым планом. Переход фона y410–480 с растушёвкой70px; контур торса2px. Подготовленные очищенные изображения находятся в public/.
4. Начальный hit: sin/cos сдвиги15×8px, scale1.06→1, blur4→0; спад на кадрах5–13.
5. Красный ключ по всему изображению: hue0°, полное сохранение до28°, спад до40° в стандартной шкале hue0–360°, saturation0–4/255 плавно включает слабые красные. Остальные пиксели остаются grayscale. Финальный красный слой: saturate1.15/contrast1.04.
6. Независимый SVG IMPOSTOR в нижней трети: pixel/block glyphs, #c60013, тёмная обводка. На кадрах24–48 opacity0→1 и blur7→0. Габариты: x202, y514, ширина≈875px, высота≈133px.

## Повторное применение

Композиция BloodRed: src/index.tsx; реализация: src/effects.tsx. Установить зависимости: npm install. Предпросмотр: npx remotion studio src/index.tsx. Экспорт: npx remotion render src/index.tsx BloodRed out/recreated.mp4 --concurrency=1.

scripts/keep-one-color.py создаёт прозрачный слой сохранённого оттенка из любого RGB-изображения. Требует Pillow и NumPy. Пример: python scripts/keep-one-color.py public/red-rich-base.png /tmp/red-detail.png --hue 0 --inner 28 --outer 40 --saturation-feather 4. В Remotion положить grayscale(1) исходное изображение под результат; дополнительная цветокоррекция задаётся отдельно. Для другого оттенка поменять --hue в градусах; для видео применять ключ к последовательности собственных исходных кадров.

## Урок из пользовательской правки

Ранняя поза847.0 содержит значительно меньше видимой крови: настройка hue key не восстановит отсутствующие в ней участки. Для этой сцены проверять площадь красного на руках и торсе в поздней фазе, а не только наличие красных пикселей. Порог насыщенности12–35 также терял приглушённые красные. Готовность следует проверять по распределению цвета рядом с оригиналом. Чистую подложку показывать отдельно, чтобы отличать остатки старых букв от намеренно размытого входа нового титра.

## Проверка и ограничения

TypeScript и72-кадровый Remotion-экспорт выполнены. ChatGPT v4 проверил четыре синхронных кадра и чистую подложку: значимый дефицит красного устранён; старых букв и грубых швов не видно. Проверка ChatGPT не подтверждает плавность MP4. Пользователь утвердил итоговое сравнение.

Это частичное воссоздание: две исходные позы растворяются вместо непрерывной игровой трансформации; фон/финальная поза заморожены. Изображения и часть исходной цветокоррекции унаследованы, восстановление фона и шрифт приблизительны. RGB fringe входа опущен. Эффект grayscale + hue key, hit и титр реализованы отдельными слоями; цельный смонтированный оригинал не подставлен вместо реализации.
