# Пять отобранных нетекстовых референсов Maxor

Пользователь попросил сохранить эту подборку2026-10-07. Статус: утверждён отбор, реализаций Remotion и их апрува ещё нет. [Источник](https://www.youtube.com/watch?v=I6qlhmjkQ44). [Просмотр фрагментов](index.html). 1280×720,60fps,без звука.

## Цветной персонаж в бесцветном мире

164.80–167.20сек. [Оригинал](clips/01-selective-color.mp4). Обесцвечивается окружение, красные детали персонажа и интерфейса сохраняются. Это выборочный цвет; точную маску или hue-key из готового ролика установить нельзя.

## Коллаж из игровых окон

172.50–174.15сек. [Оригинал](clips/02-ui-collage.mp4). Чёрно-белые части интерфейса и портрет собираются в отдельные панели; цветная карточка перекрывает их на переднем плане. Крупный заголовок сопутствующий, не предмет нетекстового приёма.

## Фокус на тёмной области

189.45–190.90сек. [Оригинал](clips/03-dark-focus.mp4). Широкий кадр постепенно приближается; края размываются и темнеют, выделенная зона получает фиолетовый оттенок. Надписи сопутствующие, не предмет отбора.

## Мем внутри увеличенного интерфейса

192.60–194.00сек. [Оригинал](clips/04-meme-in-ui.mp4). Весь игровой кадр увеличивается, мемное видео раскрывается внутри панели предметов, перекрывая часть UI; исходная рамка игрового окна сохраняется.

## Глитч-вход видео-реакции

215.60–216.80сек. [Оригинал](clips/05-reaction-glitch.mp4). Приближение к игровому персонажу с размытыми краями сменяется широким планом с кратким RGB-смещением и фиолетовым оттенком; справа отдельное видео в мемной рамке.

## Следующий шаг

Для выбранного приёма проверить вход/выход последовательными кадрами60fps; затем реализовать отдельные слои в Remotion, сделать оригинал-слева/повтор-справа, пройти независимое ChatGPT-ревью при доступности и пользовательский апрув. После этого добавить именно утверждённый повтор в галерею Maxor. Исходные клипы этой подборки не являются реализациями эффектов.

Просмотр: обзор159.50–220.00 и детальные выборки10fps; полный покадровый просмотр не заявляется. Native игровые частицы и UI различать с авторскими наложениями.
