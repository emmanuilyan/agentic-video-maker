# PNG-превью в выдаче скиллов

Если задача дала визуальный результат, приложи к нему **один полезный PNG**, который помогает быстро увидеть результат. Покажи его в финальном сообщении рядом с основным файлом и укажи путь. Для видео основным результатом остаётся MP4, PNG — его наглядное превью.

## Выбор картинки

| Результат | PNG для выдачи |
|---|---|
| Готовый Short или анимированная сцена | Контакт-лист ключевых моментов из финального видео. Для короткого одноактного демо достаточно одного чистого кадра. |
| Подготовка комикса или визуальный план до рендера | Контакт-лист финальных кандидатов и нужные вертикальные кропы. Показывай именно текущую версию на пользовательском ревью. |
| Выбранное изображение или мем | Сам выбранный PNG. Если оригинал в другом формате и PNG нужен пользователю, создай PNG-копию без изменения оригинала. |
| Редизайн captions, разметки, карты или UI | Кадр или скриншот, где хорошо видна изменённая деталь; добавь второй кадр только если он показывает существенное состояние, которое не видно на первом. |
| Звук или мультимедиа без значимого визуального изменения | PNG-волна/спектр только когда она помогает оценить тайминг или уровень; иначе не добавляй искусственную картинку. |
| Документация, API-справка, транскрипт или непоказанный код | PNG не нужен, если пользователь не просит объяснить это визуально. |

## Получение и показ

- Бери кадры из уже проверенного финального рендера или используй PNG, созданный в ходе QA. Для MP4 контакт-лист должен представлять финальную версию, а не устаревший proxy.
- Если подходящий QA-контакт-лист уже есть, повторно используй его. Если он JPEG, можно преобразовать именно этот файл в PNG; не перерендеривай видео ради смены формата.
- Не показывай технические оверлеи, случайный пустой кадр, промежуточную версию или лист десятков почти одинаковых кадров. Выбери композицию, на которой читаются основные изменения.
- Создавай новый still или скриншот, только если его получение соразмерно задаче и не обходит ограничение на рендер. Сохраняй его рядом с результатом, например `out/preview/final-contact.png`.
- В финале встраивай PNG через абсолютную ссылку и рядом оставляй ссылку на основной артефакт. Если подходящего PNG нет или визуальный результат отсутствует, прямо пропусти его; не подменяй превью выдуманной схемой.
